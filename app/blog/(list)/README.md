# なぜ /blog の一覧だけルートグループに入れているか

`app/blog/loading.tsx` を置くと、その Suspense 境界は `/blog` 配下の
すべての子セグメント（`[slug]` や `tag/[tag]`）にも適用される。
その結果、非同期ページで `notFound()` を呼んでも、先にシェルが
HTTP 200 でフラッシュされてしまい、存在しない記事URLが
「ヘッダーだけの 200 ページ」＝ソフト404 になっていた。

一覧ページとその loading.tsx を `(list)` グループに入れると、
URL は `/blog` のまま、loading 境界は一覧ページだけに限定される。
`/blog/<不明slug>` と `/blog/tag/<不明tag>` は正しく 404 を返す。

**このディレクトリの外（`app/blog/` 直下）に loading.tsx を置かないこと。**
置いた時点でソフト404が再発する。
